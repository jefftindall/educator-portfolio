# Brand & UI style guide

**Placeholder for the content phase.** The foundational milestone ships a plain hello-world page with no styling.

When permanent content lands, define tokens in `src/styles/global.css` and brand constants in `src/lib/site.ts`. A living visual reference page (for example `/style-guide`) can follow the pattern used on sibling portfolio sites.
